# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SimplyVest or the Solana Token Distribution Protocol, please report it privately.

**Do not** create a public GitHub issue. Instead, contact the team directly.

We will acknowledge receipt within 48 hours and provide an estimated timeline for a fix.

## Scope

This security policy covers:

- The Solana Anchor program (`solana-tdp`) and its on-chain instructions
- The Cloudflare API Worker and its endpoints
- The TypeScript SDK (`@solana-tdp/sdk`)
- Authentication and authorization logic (Privy integration)
- Smart contract integration and token custody

## Safe Harbor

We support coordinated disclosure. Security researchers who report vulnerabilities responsibly will not face legal action.

## Security Architecture

See the [Security Model](https://docs.simplyvest.xyz/protocol/security/) documentation for a detailed breakdown of our security architecture, test coverage, and known gaps.
